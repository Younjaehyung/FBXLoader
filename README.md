### **개발기간**

### **프로젝트 설명**
Majestro 프레임워크에서 사용된 FBX Converter입니다.<br>
디자이너가 제작한 FBX파일을 FBX SDK을 활용하여 Animation, Skeleton, Mesh(+Materials)로 분리하여 <br>
Binary로 추출하는 프로젝트입니다.<br>
추출된 프로젝트는 Majestro 프레임워크에서 로드하여 사용가능합니다.

Binary파일과 이를 사람이 해석가능한 Text파일로 2종류로 추출됩니다.
